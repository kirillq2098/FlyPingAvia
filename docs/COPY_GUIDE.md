## Основная формулировка (fixed copy)

> FlyPing — сторож цены на конкретную поездку, а не каталог из сотен рейсов.

На этапе MVP используется **зафиксированный вариант текста**. A/B-тестирование **не внедрялось**.

## Сценарий для пользователя

1. Указывает направление и даты.
2. Указывает цену, за которую готов купить билет.
3. FlyPing регулярно проверяет стоимость.
4. Получает уведомление, когда цена подходит.
5. По кнопке переходит к покупке у партнёра.

## Что пользователь не должен ожидать

- выдачу из сотен рейсов и фильтры метапоисковика;
- бронирование или продажу билета внутри FlyPing;
- гарантированную фиксацию цены на сайте партнёра;
- обещание «самой низкой цены на рынке» без данных.

**Билет покупается на сайте партнёра.** FlyPing **не гарантирует** сохранение цены.

## Glossary

| Внутренний термин | Пользовательский текст |
| ----------------- | ---------------------- |
| Watch | Подписка |
| Price checker | FlyPing проверяет цену |
| Threshold | Максимальная цена / ваш порог |
| Flexible dates | Гибкие даты |
| Alert | Уведомление о цене |
| Provider | Партнёр / сайт партнёра |

В пользовательских сообщениях не показывать: `Watch`, `checker`, `provider`, `threshold`, `FSM`, `API`, `cron`, `polling` (исключение — техническая документация и код).
