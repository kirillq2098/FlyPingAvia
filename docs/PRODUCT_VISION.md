## Зачем продукт

Люди хотят купить авиабилет дешевле, но не готовы каждый день вручную проверять цены.  
**FlyPingAvia** следит за выбранным маршрутом и сообщает, когда цена стала **не выше порога пользователя**. В сообщении — ссылка на поиск билетов с партнёрским маркером.

Формулировка из текущего README: пользователь задаёт маршрут и порог — бот следит и присылает алерт; в алертах партнёрская ссылка (CPA).

## Для кого (факт vs гипотеза)

**Факт из продукта:** интерфейс и копирайт на русском; валюта по умолчанию `rub`; ссылки ведут на `aviasales.ru`; справочник городов/аэропортов — Travelpayouts `data/ru/…`.

## Ценностное предложение (как реализовано сейчас)

| Обещание | Как сделано в продукте |
|----------|-------------------------|
| Указать маршрут словами | Резолв городов/аэропортов (`services/locations.py`), поиск по городу + flightable airports |
| Понять «дёшево / обычно / дорого» | Вилка по кэш-ценам (P25 / median / P75), пресеты порога |
| Следить за ценой | Сущность `Watch`, фоновый `PriceChecker` |
| Открыть билеты | `build_affiliate_url` → aviasales.ru с `marker` |
| Удобный UI | Telegram-бот + Mini App (вкладки «Поиск» / «Подписки») |

## Что умеет продукт сегодня (не roadmap)

### Telegram-бот

- Команды: `/start`, `/help`, `/add`, `/watch`, `/list`, `/unwatch`, `/check`.
- Reply-меню: открыть приложение (если задан `WEBAPP_URL`), добавить, маршруты, проверить, помощь.
- FSM добавления: откуда → куда → дата вылета (или любая) → one-way / round → дата возврата → превью и порог.
- Популярные маршруты на старте: MOW→AYT/IST/DXB/SSH, LED→AYT.
- Карточки подписок, удаление, ручная проверка.

### Mini App

- Поиск: origin/destination, дата, one-way/round, вилка, порог, «Следить за ценой».
- Подписки: список, удаление, обновление.
- Auth: Telegram `initData` (HMAC); для браузера — `WEBAPP_DEV_USER_ID`.

### Данные и алерты

- SQLite: `users`, `watches` (маршрут, даты, pax-поля, порог, last_price, last_alert_price, is_active).
- Интервал проверки: `CHECK_INTERVAL_MINUTES` (по умолчанию 30) или `CHECK_INTERVAL_SECONDS`.
- Алерт, если `quote.price <= max_price`.

## Что сознательно не обещаем пользователю сейчас

Зафиксировано в коде/UI (см. [DECISIONS](DECISIONS.md)):

- выбор числа взрослых/детей в UI **скрыт** — всегда 1 взрослый (нет доступа к Flight Search API у партнёра);
- round-trip без live search ≈ сумма двух one-way (это явно пишется пользователю);
- без `TRAVELPAYOUTS_TOKEN` — demo-цены (не рыночные);
- без стабильного HTTPS `WEBAPP_URL` кнопка Mini App скрыта.
