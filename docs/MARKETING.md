## Что уже можно использовать для коммуникаций (факт продукта)

Сообщения продукта (бот / Mini App):

- «FlyPingAvia — мониторинг цен на авиабилеты»
- «Следите за ценой. Покупайте вовремя.»
- Вилка: дёшево / обычно / дорого
- Алерт: «Цена ниже порога» + кнопка к билетам

Популярные маршруты на `/start` (как намёк на спрос, не как аналитика):

- MOW → AYT, IST, DXB, SSH  
- LED → AYT

## Ограничения, которые влияют на маркетинг

1. Без стабильного HTTPS Mini App «отваливается» для пользователей Telegram.  
2. Выбор пассажиров скрыт — нельзя честно рекламировать «цену за семью», пока нет Flight Search.  
3. Round-trip без live ≈ сумма one-way — нельзя обещать «точную цену RT» в креативах.  
4. CPA-выручка зависит от клика по Aviasales — креатив должен вести к действию «следить → дождаться алерта → открыть билеты».

## Минимальный go-to-market для текущего MVP

Пока нет ответов на TODO, безопасный цикл:

1. Стабильный бот + `WEBAPP_URL`  
2. Небольшая закрытая группа пользователей  
3. Смотрим: создают ли подписки и приходят ли алерты  
4. Смотрим в кабинете Travelpayouts: есть ли клики/брони по маркеру  
5. Только после этого — платный/блогерский трафик
