# FlyPing

Travel-tech лендинг сервиса мониторинга цен на авиабилеты.

## Стек

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion

## Запуск

```bash
npm install
npm run dev
```

## Визуальный язык

Аэропортовая навигация + travel editorial + мониторинг цен:
коды аэропортов, маршрутные линии, tabular prices, системные mono-подписи.
