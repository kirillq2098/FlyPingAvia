# FlyPing

Лендинг travel-tech сервиса FlyPing — мониторинг цен на авиабилеты и уведомления в Telegram.

## Стек

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Запуск

```bash
npm install
npm run dev
```

## Структура

```text
app/                 # маршруты, SEO, metadata
components/          # секции лендинга и UI
lib/                 # конфиг и контент
types/               # типы под будущие модули
public/              # статика
```
